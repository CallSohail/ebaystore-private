# Strongly recommended for scraping. eBay's edge fingerprints the TLS
# handshake, and plain `requests` produces one that matches no real browser —
# so a request claiming to be Chrome in its User-Agent contradicts itself at
# the TLS layer. curl_cffi replays a real browser's fingerprint so the two
# agree, which is the difference between most listings being blocked and most
# going through. The app runs without it and falls back to `requests`.
